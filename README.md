



# wx-gzh-downloader
【微信公众号文章下载工具公众号文章下载HTML格式，markdown格式，txt格式，点赞数，转发数，收藏数，评论数导出数据到excel表格

## ✨ 功能特性
- ✅ 公众号文章下载HTML格式，markdown格式，txt格式
- ✅ 自动下载文章内的视频
- ✅按照原文排版样式下载HTML
- ✅ 自定义下载视频时间范围和数量
- ✅ 抓取文章互动数据：点赞 / 转发 / 收藏 / 评论数量
- ✅ 批量导出采集数据至 Excel
- ✅ 可视化操作界面
